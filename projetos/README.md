# Projetos

Esta pasta reúne pequenos projetos desenvolvidos durante meus estudos de lógica de programação em Portugol.

Os programas foram criados com o objetivo de aplicar conceitos como entrada e saída de dados, estruturas condicionais, estruturas de repetição, funções, validação de dados e operações matemáticas.

## Calculadora

Arquivo: [`calculadora.por`](./calculadora.por)

Calculadora com menu de operações matemáticas.

### Conceitos praticados

- Entrada e saída de dados.
- Estruturas de repetição.
- Estruturas condicionais.
- Operações matemáticas.
- Uso da biblioteca Matemática.
